CRE のドキュメントサイトとプロトタイプが、利用者のデータをどう扱うかをまとめています。
機能が増えたら、このページに追記します。

## ドキュメントサイト（docs.cre.run）

- 静的なページだけを配信します。アクセス解析のタグや外部スクリプトは置いていません
- 配信は Cloudflare Workers で、Cloudflare のリクエストログ（IP アドレス・リクエストしたパスなど）の対象になることがあります

## Message Editor（editor.cre.run）

- 判定データは URL の `#` 以降に載せて渡します。`#` 以降はブラウザがサーバーに送らないため、Cloudflare にも CRE にも届きません
- 画面はデータをブラウザの中だけで復号・表示します。サーバーへの送信、外部サービスへの連携、ブラウザへの保存（履歴とブックマークを除く）は行いません。編集した本文は画面を閉じると消えます
- 一方、URL には判定データが圧縮されただけで入っています。URL を知っている人は誰でも内容を読めるので、実際のお客様の情報を含む URL は、社内の権限管理された場所にだけ貼ってください
- 根拠のリンクは `http(s)` だけを受け付け、新しいタブで開きます。開いた先には判定データの URL を渡しません
- 詳しくは [Message Editor](/features/message-editor) の「判定データの扱いについて」を見てください

これらの約束は `apps/message-editor` のテストで確かめ続けています（送信・保存する API を使っていないこと、外部スクリプトを読み込まないこと、
実際のブラウザで開いても自分のオリジン以外に通信せず、ブラウザに何も保存しないこと）。
