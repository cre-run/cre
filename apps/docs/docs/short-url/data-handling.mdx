## 確かめ方

「テスト」列のバッジは、その約束を確かめ続けているテスト（`apps/short-url`）へのリンクです。

<Badge variant="success" size="xs">
  E2E
</Badge>
は実際のブラウザで（ローカルで動かした Worker と D1 に、Access と同じ形の JWT を付けて開きます）、
<Badge variant="success" size="xs">
  単体
</Badge>
はコードの形で確かめます（Worker の処理を、偽の D1 とテスト用の鍵で署名した Access の JWT
で動かします）。リンク先はテストの行です。 バッジのテスト名と実際のテストは
`tests/guide-promises.test.ts` が突き合わせるので、どちらかだけを変えると落ちます。

テストしない約束: ブラウザの履歴と URL を貼った先に残ることは、ブラウザや外部サービスの振る舞いなので確かめません。
