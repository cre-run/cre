<Badge variant="warning">planned</Badge>
この機能はまだありません。作る前に約束として決めるための下書きです。 Message Editor
の約束（[データの取り扱い](/message-editor/data-handling)）はそのままです。

| 経路                           | 判定データ                                                                                      | テスト |
| ------------------------------ | ----------------------------------------------------------------------------------------------- | ------ |
| 短縮 URL のサーバー（自組織）  | **届きます。** 登録と開くときだけです。CRE の運営者には届きません                               | —      |
| データベースとそのバックアップ | **暗号文だけが残ります。** サーバーの鍵がなければ読めません。削除するとすぐに開けなくなります   | —      |
| 短縮 URL を開ける人            | **組織のメールアドレスでログインした人だけです。** リンクのプレビューや検索エンジンには出ません | —      |
| ブラウザの履歴・URL を貼った先 | **残ります。** 移った先の Message Editor の URL は、ログインなしで開けます                      | —      |

「テスト」列は、実装するときに約束ごとのテストへのバッジに置き換えます。
