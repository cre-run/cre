この機能はまだありません。[短縮 URL](/short-url)
が判定データをどう扱うかを、作る前に約束として決めるための下書きです。

Message Editor の約束（[データの取り扱い](/message-editor/data-handling)）はそのままです。
短縮 URL は、判定データを自組織のサーバーに暗号化して預けます。その部分について、次のように約束します。

## どこに届き、どこに残るか

| 経路                                                 | 判定データ                                                                                                               | テスト |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------ |
| 短縮 URL のサーバー（自組織の Cloudflare）           | **届きます。** 登録のときと開くときだけです                                                                              | —      |
| CRE の運営者                                         | **届きません。** サーバーは自組織のものです                                                                              | —      |
| データベース（D1）とそのバックアップ                 | **暗号文だけが残ります。** サーバーの鍵がなければ読めません。バックアップ（Time Travel）には削除の後も最長 30 日残ります | —      |
| 短縮 URL を開ける人                                  | **組織のメールアドレスでログインした人だけです。** URL を知っているだけでは開けません                                    | —      |
| リンクのプレビュー（Slack などの展開）・検索エンジン | **渡しません。** ログインの後ろにあり、検索エンジンにも載せません（`noindex`）                                           | —      |
| サーバーのログ                                       | **判定データ・Secret・メールアドレスは書きません。** URL（ID）は残りますが、ID だけでは開けません                        | —      |
| ブラウザの履歴                                       | **残ります。** 移った先の Message Editor の URL は判定データ全体を含み、ログインなしで、期限が切れても開けます           | —      |
| URL を貼ったチャット・チケット                       | **残ります。** 期限までは、組織の人なら URL を知っていれば読めます                                                       | —      |

## 有効期限・削除・設定

| 場面                                                         | どうなるか                                             | テスト |
| ------------------------------------------------------------ | ------------------------------------------------------ | ------ |
| 有効期限が切れたとき                                         | 開けなくなります。データベースには暗号文のまま残ります | —      |
| 削除したとき                                                 | すぐに開けなくなり、データベースから消えます           | —      |
| サーバーの鍵・Access・許可するドメインが未設定のとき         | 作ることも開くこともできません                         | —      |
| Secret がない・違う登録、Message Editor が表示できないデータ | 登録しません                                           | —      |

## 確かめ方

まだ実装していないので、「テスト」列はすべて — です。実装するときに約束ごとにテストを書き、[Message Editor](/message-editor/data-handling) と同じようにバッジを置きます。
ブラウザの履歴・URL を貼った先・Cloudflare のバックアップは、ブラウザや外部のサービスの振る舞いなのでテストしません。
