[Message Editor](/message-editor) の URL は、判定データを `#d=` に載せるため長くなります（見本データで約 3,600 文字）。
Slack のボタン（3,000 文字まで）のように長さに上限がある場所には載りません。短縮 URL を使うと、同じ内容を短い URL で渡せます。

## できること

- Bot などが判定データを登録すると、短縮 URL が返ってきます
- 短縮 URL を開くと、組織のメールアドレスでログインしたうえで、Message Editor にその判定データが表示されます
- 有効期限が来るか削除すると、開けなくなります

短縮 URL のサーバーは、自組織の Cloudflare にセルフホストして使います。
作れるのは管理者が Secret を発行した Bot などだけで、開けるのは組織のメールアドレスでログインした人だけです。

## URL の形

```text
https://short.example.com/id/0f8c3a52-6b1e-4d7a-9c25-3e4f5a6b7c8d
```

ID はランダムな UUID（v4）です。長さは判定データの大きさによらず一定です。

| 渡し方                         | URL の長さ（見本データ） | Slack のボタン（3,000 文字まで） |
| ------------------------------ | ------------------------ | -------------------------------- |
| Message Editor の URL（`#d=`） | 3,578 文字               | 載りません                       |
| 短縮 URL                       | 65 文字                  | 載ります                         |

## 開いたときの動き

1. まだログインしていなければ、Cloudflare Access のログイン画面が出ます。組織のメールアドレスでログインします
2. Message Editor（`https://editor.cre.run/#d=…`）に移ります。移ったあとは、今の Message Editor と同じです

開けないときは、次のように表示します。

| 表示                              | 理由                                                    |
| --------------------------------- | ------------------------------------------------------- |
| このリンクは開けません            | 有効期限が切れた、削除された、または URL が間違っている |
| このメールアドレスでは開けません  | ログインしたメールアドレスのドメインが許可されていない  |
| 短縮 URL の設定が終わっていません | 管理者がサーバーの設定を終えていない                    |

## 有効期限

- 既定は **30 日** です。登録するときに 1 時間から 90 日の間で指定できます
- 期限の前でも、Bot などから削除できます
- 開いたあとの Message Editor の URL はブラウザの履歴に残り、期限が切れても履歴からは開けます

## 短縮 URL を作る（Bot の開発者向け）

管理者から受け取った Secret を付けて登録します。`data` には Message Editor の URL の `#d=` より後ろを入れます。

```bash
# link.json: {"data": "<#d= より後ろの値>", "expiresIn": 604800}
curl -X POST https://short.example.com/api/links \
  -H "Authorization: Bearer $CRE_SHORT_URL_SECRET" \
  -H "Content-Type: application/json" \
  --data-binary @link.json
# → {"id": "0f8c…", "url": "https://short.example.com/id/0f8c…", "expiresAt": "2026-10-19T09:00:00.000Z"}

curl -X DELETE https://short.example.com/api/links/<ID> \
  -H "Authorization: Bearer $CRE_SHORT_URL_SECRET"
```

- `expiresIn` は秒です。省略すると 30 日です
- Message Editor が表示できないデータは登録しません

サーバーの用意は[セルフホストの設定](/short-url/self-hosting)、データがどこに残るかは[データの取り扱い](/short-url/data-handling)にまとめています。
