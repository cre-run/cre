[Message Editor](/message-editor)
のプロトタイプ（editor.cre.run）が、判定データをどう扱うかをまとめています。 判定データを URL
以外で受け渡す仕組みができたら、このページを更新します。

## どこに届き、どこに届かないか

約束の末尾の <Badge variant="success" size="xs">tested</Badge> は、その約束を確かめ続けているテストへのリンクです（ホバーでテスト名）。

| 経路                                   | 判定データ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| サーバー（Cloudflare）                 | **届きません。** URL の `#` 以降はブラウザがサーバーに送らないためです <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="判定データは、画面を操作しても外部に送られず、ブラウザにも保存されない">tested</Badge></a>                                                                                                                                                                                                                                                                  |
| 画面からの送信・外部サービスへの連携   | **行いません。** データはブラウザの中だけで復号・表示します <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts"><Badge variant="success" size="xs" tooltip="画面のコードは、判定データを送信・保存する API を使っていない">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts"><Badge variant="success" size="xs" tooltip="index.html は自前のスクリプトだけを読み込み、検索エンジンには載せない">tested</Badge></a>                                                               |
| ブラウザへの保存                       | **行いません。** 編集した本文は画面を閉じると消えます <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="判定データは、画面を操作しても外部に送られず、ブラウザにも保存されない">tested</Badge></a>                                                                                                                                                                                                                                                                                   |
| 根拠のリンクの遷移先                   | **渡しません。** リンクは新しいタブで開き、元の URL（判定データ）も `window.opener` も渡しません <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="根拠のリンクは新しいタブで開き、開いた先に判定データの URL も window.opener も渡さない">tested</Badge></a>                                                                                                                                                                                                                        |
| `encode` で URL を作る手順             | **キャッシュに残しません。** `vp run` ではなく `node` で直接実行する手順を案内します <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts"><Badge variant="success" size="xs" tooltip="README・ガイドの手順どおりに encode を実行すると、--base を付けた URL ができる">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts"><Badge variant="success" size="xs" tooltip="ドキュメントの encode の例は vp run を使わない（出力をキャッシュして古い URL を返すため）">tested</Badge></a> |
| ブラウザの履歴・ブックマーク           | **残ります**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| URL を貼ったチャット・チケット・メール | **残ります。** URL を知っている人は誰でも内容を読めます                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

URL には判定データ（問い合わせ本文・宛名・返信文・根拠の引用）が圧縮されただけで、暗号化はされずに入っています。
実際のお客様の情報を含む URL は、社内の権限管理された場所にだけ貼ってください。

## 受け付けないデータ

次のデータは表示せず、見本データとエラーを表示します。

- 形式が合わないもの（必須の項目がない、段落 ID が重複している、など） <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/payload.test.ts"><Badge variant="success" size="xs" tooltip="形式の違うデータは読み込まない">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/payload.test.ts"><Badge variant="success" size="xs" tooltip="入れ子の必須項目や値が不正なデータは読み込まない">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/critical-path.e2e.ts"><Badge variant="success" size="xs" tooltip="壊れた判定データでは見本データとエラーを表示する">tested</Badge></a>
- 根拠のリンクが `http(s)` 以外のもの（`javascript:` などはリンクにしません） <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/payload.test.ts"><Badge variant="success" size="xs" tooltip="根拠のリンクは http(s) だけを受け付ける">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="http(s) 以外のリンクを含むデータは読み込まず、見本データとエラーを表示する">tested</Badge></a>
- 圧縮データが 10 万文字を超えるもの、展開後が 1 MB を超えるもの（展開しながら大きさを見て、超えた時点で打ち切ります） <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/payload.test.ts"><Badge variant="success" size="xs" tooltip="大きすぎる圧縮データは展開しない">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="大きすぎるデータは展開せずにエラーを表示する">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/payload.test.ts"><Badge variant="success" size="xs" tooltip="展開すると大きくなるデータ（展開爆弾）は、途中で打ち切る">tested</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts"><Badge variant="success" size="xs" tooltip="展開すると大きくなるデータ（展開爆弾）は、途中で打ち切ってエラーを表示する">tested</Badge></a>

## 作成者を検証しないこと

URL は誰でも作れ、署名もありません。画面が「確認済み」と表示しても、それは URL に書かれていた値です。
出所の分からない URL の内容を根拠にしないでください。

## 確かめ方

<Badge variant="success" size="xs">
  tested
</Badge>
の付いた約束は、リンク先のテスト（`apps/message-editor`）で確かめ続けています。
バッジのテスト名と実際のテストは `tests/guide-promises.test.ts`
が突き合わせるので、どちらかだけを変えると落ちます。

テストしない約束: ブラウザの履歴・ブックマークと、URL を貼った先に残ることは、ブラウザや外部サービスの振る舞いなので確かめません。
作成者を検証しないことは、検証の仕組みがないという事実なので、テストではなく本文に書いています。
