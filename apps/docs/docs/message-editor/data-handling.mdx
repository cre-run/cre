[Message Editor](/message-editor)
のプロトタイプ（editor.cre.run）が、判定データをどう扱うかをまとめています。 判定データを URL
以外で受け渡す仕組みができたら、このページを更新します。

## どこに届き、どこに届かないか

| 経路                                   | 判定データ                                                                                                                                        | テスト                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| サーバー（Cloudflare）                 | **届きません。** URL の `#` 以降はブラウザがサーバーに送らないためです                                                                            | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L51"><Badge variant="success" size="xs">E2E</Badge></a></span>                                                                                                                                           |
| 画面からの送信・外部サービスへの連携   | **行いません。** データはブラウザの中だけで復号・表示します                                                                                       | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L53"><Badge variant="success" size="xs">単体</Badge></a></span>                                                                                                                                                            |
| 外部スクリプト・解析タグ               | **読み込みません。** 検索エンジンにも載せません                                                                                                   | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L64"><Badge variant="success" size="xs">単体</Badge></a></span>                                                                                                                                                            |
| ブラウザへの保存                       | **行いません。** 送る前にやることに付けたチェックは画面を閉じると消えます（クリップボードにコピーした文面を除く）                                 | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L71"><Badge variant="success" size="xs">E2E</Badge></a></span>                                                                                                                                           |
| 根拠のリンクの遷移先                   | **渡しません。** リンクは新しいタブで開き、元の URL（判定データ）も `window.opener` も渡しません                                                  | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L93"><Badge variant="success" size="xs">E2E</Badge></a></span>                                                                                                                                           |
| `encode` で URL を作る手順             | **キャッシュに残しません。** `vp run` ではなく `node` で直接実行する手順を案内します                                                              | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L73"><Badge variant="success" size="xs">単体</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L90"><Badge variant="success" size="xs">単体</Badge></a></span> |
| クリップボード                         | **コピーしたときだけ残ります。** 返信プレビューのコピーボタンを押すと、送る文面（宛名・本文・結び）がクリップボードに入り、画面を閉じても残ります | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L160"><Badge variant="success" size="xs">E2E</Badge></a></span>                                                                                                                                          |
| ブラウザの履歴・ブックマーク           | **残ります**                                                                                                                                      | —                                                                                                                                                                                                                                                                                                                                                                   |
| URL を貼ったチャット・チケット・メール | **残ります。** URL を知っている人は誰でも内容を読めます                                                                                           | —                                                                                                                                                                                                                                                                                                                                                                   |

URL には判定データ（問い合わせ本文・宛名・返信文・根拠の引用）が圧縮されただけで、暗号化はされずに入っています。
実際のお客様の情報を含む URL は、社内の権限管理された場所にだけ貼ってください。

## 受け付けないデータ

次のデータは表示しません。廃止した形式のデータ以外は、見本データとエラーを表示します。

| 受け付けないデータ                                               | 扱い                                                                               | テスト                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 形式が違うもの（`version` が違う、圧縮データが壊れている、など） | 表示せず、見本データとエラーを表示します                                           | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L98"><Badge variant="success" size="xs">単体</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L154"><Badge variant="success" size="xs">E2E</Badge></a></span>  |
| 必須の項目がない・値が不正・ID が重複しているもの                | 表示せず、見本データとエラーを表示します                                           | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L107"><Badge variant="success" size="xs">単体</Badge></a></span>                                                                                                                                                                              |
| 根拠のリンクが `http(s)` 以外のもの                              | `javascript:` などはリンクにせず、データごと受け付けません                         | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L154"><Badge variant="success" size="xs">単体</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L123"><Badge variant="success" size="xs">E2E</Badge></a></span> |
| 圧縮データが 10 万文字を超えるもの                               | 展開せずにエラーを表示します                                                       | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L174"><Badge variant="success" size="xs">単体</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L136"><Badge variant="success" size="xs">E2E</Badge></a></span> |
| 展開後が 1 MB を超えるもの                                       | 展開しながら大きさを見て、超えた時点で打ち切ります                                 | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/tests/data-handling.test.ts#L179"><Badge variant="success" size="xs">単体</Badge></a> <a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L142"><Badge variant="success" size="xs">E2E</Badge></a></span> |
| 廃止した形式（段落ごとに判定する `version` 1）のデータ           | 表示せず、エラーではなく、形式を廃止したことと新しい形式への切り替え方を案内します | <span style={{ whiteSpace: "nowrap" }}><a href="https://github.com/cre-run/cre/blob/main/apps/message-editor/e2e/guide-message-editor-data-handling.e2e.ts#L188"><Badge variant="success" size="xs">E2E</Badge></a></span>                                                                                                                                                             |

## 作成者を検証しないこと

URL は誰でも作れ、署名もありません。画面が「確認済み」と表示しても、それは URL に書かれていた値です。
出所の分からない URL の内容を根拠にしないでください。

## 確かめ方

「テスト」列のバッジは、その約束を確かめ続けているテスト（`apps/message-editor`）へのリンクです。

<Badge variant="success" size="xs">
  E2E
</Badge>
は実際のブラウザで、
<Badge variant="success" size="xs">
  単体
</Badge>
はコードの形で確かめます。リンク先はテストの行です。 バッジのテスト名と実際のテストは
`tests/guide-promises.test.ts` が突き合わせるので、どちらかだけを変えると落ちます。

テストしない約束: ブラウザの履歴・ブックマーク、URL を貼った先、コピーした文面が画面を閉じた後もクリップボードに残ることは、ブラウザ・OS や外部サービスの振る舞いなので確かめません。
作成者を検証しないことは、検証の仕組みがないという事実なので、テストではなく本文に書いています。
