[Message Editor](/message-editor)
のプロトタイプ（editor.cre.run）が、判定データをどう扱うかをまとめています。 判定データを URL
以外で受け渡す仕組みができたら、このページを更新します。

## どこに届き、どこに届かないか

| 経路                                   | 判定データ                                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| サーバー（Cloudflare）                 | **届きません。** URL の `#` 以降はブラウザがサーバーに送らないためです                           |
| 画面からの送信・外部サービスへの連携   | **行いません。** データはブラウザの中だけで復号・表示します                                      |
| ブラウザへの保存                       | **行いません。** 編集した本文は画面を閉じると消えます                                            |
| 根拠のリンクの遷移先                   | **渡しません。** リンクは新しいタブで開き、元の URL（判定データ）も `window.opener` も渡しません |
| ブラウザの履歴・ブックマーク           | **残ります**                                                                                     |
| URL を貼ったチャット・チケット・メール | **残ります。** URL を知っている人は誰でも内容を読めます                                          |

URL には判定データ（問い合わせ本文・宛名・返信文・根拠の引用）が圧縮されただけで、暗号化はされずに入っています。
実際のお客様の情報を含む URL は、社内の権限管理された場所にだけ貼ってください。

## 受け付けないデータ

次のデータは表示せず、見本データとエラーを表示します。

- 形式が合わないもの（必須の項目がない、段落 ID が重複している、など）
- 根拠のリンクが `http(s)` 以外のもの（`javascript:` などはリンクにしません）
- 圧縮データが 10 万文字を超えるもの、展開後が 1 MB を超えるもの（展開しながら大きさを見て、超えた時点で打ち切ります）

## 作成者を検証しないこと

URL は誰でも作れ、署名もありません。画面が「確認済み」と表示しても、それは URL に書かれていた値です。
出所の分からない URL の内容を根拠にしないでください。

## 確かめ方

約束ごとに、`apps/message-editor` で確かめ続けているテストを挙げます。
テスト名は実際のテストと同じで、どちらかだけを変えるとテストが落ちます（`tests/guide-promises.test.ts`）。

届かない・送らない・保存しない:

- 「判定データは、画面を操作しても外部に送られず、ブラウザにも保存されない」（`e2e/guide-message-editor-data-handling.e2e.ts`）
- 「画面のコードは、判定データを送信・保存する API を使っていない」（`tests/data-handling.test.ts`）
- 「index.html は自前のスクリプトだけを読み込み、検索エンジンには載せない」（`tests/data-handling.test.ts`）

根拠のリンクの遷移先に渡さない:

- 「根拠のリンクは新しいタブで開き、開いた先に判定データの URL も window.opener も渡さない」（`e2e/guide-message-editor-data-handling.e2e.ts`）

形式が合わないデータを受け付けない:

- 「形式の違うデータは読み込まない」（`tests/payload.test.ts`）
- 「入れ子の必須項目や値が不正なデータは読み込まない」（`tests/payload.test.ts`）
- 「壊れた判定データでは見本データとエラーを表示する」（`e2e/critical-path.e2e.ts`）

`http(s)` 以外のリンクを受け付けない:

- 「根拠のリンクは http(s) だけを受け付ける」（`tests/payload.test.ts`）
- 「http(s) 以外のリンクを含むデータは読み込まず、見本データとエラーを表示する」（`e2e/guide-message-editor-data-handling.e2e.ts`）

大きすぎるデータを受け付けない:

- 「大きすぎる圧縮データは展開しない」（`tests/payload.test.ts`）
- 「展開すると大きくなるデータ（展開爆弾）は、途中で打ち切る」（`tests/payload.test.ts`）
- 「大きすぎるデータは展開せずにエラーを表示する」（`e2e/guide-message-editor-data-handling.e2e.ts`）
- 「展開すると大きくなるデータ（展開爆弾）は、途中で打ち切ってエラーを表示する」（`e2e/guide-message-editor-data-handling.e2e.ts`）

URL を作る手順が、生成した URL をキャッシュに残さない:

- 「README・ガイドの手順どおりに encode を実行すると、--base を付けた URL ができる」（`tests/data-handling.test.ts`）
- 「ドキュメントの encode の例は vp run を使わない（出力をキャッシュして古い URL を返すため）」（`tests/data-handling.test.ts`）

テストしない約束: ブラウザの履歴・ブックマークと、URL を貼った先に残ることは、ブラウザや外部サービスの振る舞いなので確かめません。
作成者を検証しないことは、検証の仕組みがないという事実なので、テストではなく本文に書いています。
