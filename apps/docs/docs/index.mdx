CRE のドキュメントサイトです。現在準備中のため、内容は順次追加していきます。

## このサイトについて

- [Blume](https://useblume.dev/) で構築しています。
- `apps/docs/docs/` 配下の Markdown / MDX がそのままページになります。
- `main` ブランチへのマージで Cloudflare Workers（`cre-docs`）に自動デプロイされます。
- サイトとプロトタイプが利用者のデータをどう扱うかは、[データの取り扱い](/data-handling)にまとめています。
